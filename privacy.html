    Website privacy

    This page describes what desanya.tech does with information. It is the website policy. The Firefly Hollow game has its own policy. This is not a lawyer’s review, and it does not claim that a regulator has signed off.

    Desanya Studio is in Niota, TN. Questions about this page can go to desanyaafterdark@gmail.com. The public phone number is on the site footer.

    The game policy is separate: Firefly Hollow privacy policy. Its release date is still to be determined, so that page does not show an effective date yet.

    What this website stores

    The site is static files. It has no customer accounts and no database of form submissions. It does not run ads.

    Your browser can keep these values for this site:

    • Cart. desanya_cart_v1 in local storage is the service id and quantity. It does not store a custom price.
    • Discount flag. desanya_adj_v1 in session storage records whether a discount code is on for this visit. desanya_discount_code keeps the code text for that visit after it is accepted. It is removed when the code is removed or the discount window is closed.
    • Receipt. After a completed capture response, desanya_last_order in session storage keeps the order id, capture id, status, currency, amount, and the name and email typed at checkout. The thanks page shows a payment only from that saved record, and only at thanks/#receipt. That record is stored by this browser. It is not a receipt issued by a Desanya Studio server. Opening the thanks address by itself does not show a payment.

    Clearing this site’s data in the browser removes those values. This page does not set a retention period for them.

    Forms

    The booking form, the order form, and the chat quote form send a POST to FormSubmit at formsubmit.co, addressed to desanyaafterdark@gmail.com. Depending on the form, the fields can include name, email, phone, business name, service, project details, preferred contact, a time slot, a consent checkbox, and utm_source, utm_medium, and utm_campaign when those were in the page address. A hidden honeypot field is included. The forms set FormSubmit’s _captcha field to true, which asks FormSubmit to use its captcha. After FormSubmit accepts a submission, it sends the browser to this site’s thanks page.

    Those submissions are not stored in this website’s files. Email delivery through FormSubmit to the studio address is already in use. FormSubmit’s privacy terms say the form owner is responsible for the information collected through the form, and that FormSubmit sends that information by email. FormSubmit also documents an API that can list past submissions. A read of FormSubmit’s public site did not show the dashboard, so whether FormSubmit stores submissions, and for how long, is still unknown. This page does not claim a deletion schedule. No retention period for those emails is set in this website’s code.

    FormSubmit sources used for this description: formsubmit.co/privacy.pdf (the PDF states an effective date of January 17, 2019) and formsubmit.co/api-documentation (Get Submissions).

    Analytics

    Pages load Google Analytics 4 through the Google tag, measurement ID G-K3MKEG3RFH. The site code can send add_to_cart, generate_lead when a FormSubmit form is submitted, purchase after a completed PayPal capture, and click events for phone, email, PayPal, Calendly, and social profile links. The site code does not set a cookie expiration and does not send Consent Mode updates.

    A read-only look at the Google Analytics property for that measurement ID on 5 November 2026 showed these property settings, which are not the same thing as the cookies in the browser:

    • Event data retention was 2 months.
    • User data retention was 14 months, with reset on new activity turned on.
    • The screen said those retention controls do not affect standard aggregate reports.
    • Google signals was off. User-provided data collection was off.
    • Granular location and device data, and ads personalization, were allowed for every region listed on that screen.
    • Enhanced measurement was on for page views, scrolls, outbound clicks, site search, video engagement, file downloads, and form interactions.
    • Email redaction was on. URL query-parameter redaction was not turned on.

    The consent screen was labeled good. That is Google’s status label. It is not a legal review, and it does not mean this website shows a consent banner or that a visitor has consented. The signals analytics_storage, ad_storage, ad_user_data, and ad_personalization were inactive. Default consent does not automatically mark a visitor as consented.

    Cookie lifetime is separate from those retention settings. This website’s code does not choose a cookie expiration. Google’s tag documentation says the default _ga cookies expire after two years unless a site overrides them. This page does not treat that documented cookie default as the 2-month or 14-month retention settings above.

    Google sources for the cookie and default collection descriptions: GA4 cookie usage and GA4 data collection.

    Checkout and PayPal

    Checkout asks for a name and email in the browser. The name is placed in the PayPal order description. The email is not sent to a Desanya Studio server. PayPal’s script loads on the checkout page. Payment happens at PayPal. PayPal’s privacy statement describes what PayPal collects for a payment, including transaction details and device data. This site does not see or store card numbers.

    The on-page note uses the capture response the browser received: status, currency, and amount. A completed USD capture is what the thanks page can show. A canceled or incomplete result leaves the cart in place and does not show a payment. The saved note is not a receipt issued by a Desanya Studio server.

    Catalog prices are published in the page. While checkout is in its current configuration, the amount sent to PayPal is calculated in the browser. Freezing the price list in the page only stops a simple edit of that object. It is not a security control. An order checker in the site repository is not connected, and this website does not call it. PayPal receives the amount the current checkout path submits.

    A page at /receipt/ is prepared for a later connection to that order checker. It is not used by checkout today, because checkout does not call the checker. When a connection exists, that page shows order id, capture id, date, items, and amount only from the checker’s response for a completed capture. It does not treat amounts or status in the page address, or in desanya_last_order, as that receipt. It does not send email. PayPal may still send its own payment notification. That notification is separate, and this site does not call it the itemized receipt or guarantee that an email arrives.

    PayPal source: PayPal Privacy Statement.

    Scheduling

    The booking button is a link to a Calendly page. This site does not embed Calendly. Calendly’s own notice applies on that page. Calendly says it collects an invitee’s name and email to schedule, and that its site can collect log and device data.

    Calendly source: Calendly Privacy Notice.

    Fonts

    DM Sans and Fraunces are font files stored on desanya.tech. Pages do not request font CSS from fonts.googleapis.com or font files from fonts.gstatic.com.

    Links that leave this site

    Social profiles, YouTube, Twitch, Discord, Fiverr, and the map link go to those sites when you follow them. Their notices apply there. The pictures for those links that are stored on desanya.tech are files on this site.
